      Analysis

      Sequences are sent to the official BOLD v5 identification engine (id.boldsystems.org). The API allows 3 submissions per minute: large files take time. Metadata of the matched records (identifier, sequence, projects) come from the BOLD portal API.

        Reference usage

        Reference usage CSV

        Retrieved: ASVs whose BOLD matches include the record. LCA: ASVs whose LCA set includes it. Contribution: ASVs with an accepted assignment whose LCA set includes it. These counts describe participation; they do not show that a record was indispensable.

        Taxonomic attribution

        Attribution CSV

        Identifiers are the verbatim BOLD identified_by values of the reference records: names are not merged or normalized (ORCID column reserved). No credit goes to sequencing laboratories, storing institutions, uploaders or project managers. The fractional credit is an experimental participation indicator, not a measure of merit; the table is ordered alphabetically.
